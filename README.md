## 🛠 Products &amp; Open Source

### 🐾 [PixelFriend](https://apps.microsoft.com/detail/9NJX9Q9TSM13) · *on the Microsoft Store*
A pixel-art companion that lives above your Windows taskbar and reminds you to drink water, stretch and rest your eyes, with a focus timer and ambient sounds.
- Goes quiet during calls and fullscreen apps; downloadable character and sound packs; auto-updates
- Idle CPU cut from ~2.4% to ~1.4%, animation assets from 28 MB to under 5 MB
- `Electron` `React` `TypeScript` `MSIX` · [releases](https://github.com/ShahzaibAnwar/pixelfriend-releases)

### ⚡ [Velora Download Manager](https://github.com/ShahzaibAnwar/velora) · *public alpha*
An open-source download manager for Windows 10/11.
- Rust engine with multi-connection downloads and crash-safe resume
- Video sites and HLS/DASH streams via yt-dlp, BitTorrent via librqbit, browser extensions for Chrome, Edge and Firefox
- `Rust` `Tauri` `TypeScript` `React` · CI releases with GitHub Actions

### 🗂 [Tucklane](https://github.com/ShahzaibAnwar/tucklane) · *v0.1.0*
A privacy-first organizer for your Downloads folder.
- Sorts new and existing downloads automatically, with full undo; never overwrites, never deletes
- Custom rules, a duplicate finder (size → fingerprint → SHA-256), tray mode; nothing leaves your PC
- `Rust` `Tauri` `React`

### 🚀 [Velox PC Booster](https://github.com/ShahzaibAnwar/velox-pc-booster) · *v1.0.0*
See what is slowing your Windows PC and fix it.
- Health score, live resource monitor, startup manager, junk cleaner, storage analyzer
- Changes are reversible; no telemetry; installer and portable builds
- `Electron` `PowerShell` `C#`

### 🧭 [Skill Atlas](https://github.com/ShahzaibAnwar/skill-atlas)
One local dashboard for every AI skill you've installed across Claude Code, Codex, Gemini CLI, Antigravity and OpenCode: what each one does, how to use it and when your AI last used it.
- `Node.js` · zero dependencies · local and private

### 🎬 [Cliffhanger](https://github.com/ShahzaibAnwar/cliffhanger)
A Claude skill that runs a faceless explainer reel from idea to upload: research, script with open loops, voiceover, an animated 9:16 video and captions for 7 platforms.
- `Node.js` `ffmpeg` `ElevenLabs / Edge TTS` · used for my English and Urdu reel series

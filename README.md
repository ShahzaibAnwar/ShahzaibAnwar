## 🛠 Open-Source & Products

### ⚡ [Velora Download Manager](https://github.com/ShahzaibAnwar/velora)
**Download beautifully. Accelerate everything.** A fast, open-source download manager for Windows 10/11.
- Rust engine with multi-connection downloads, dynamic splitting and crash-safe resume
- Video sites and HLS/DASH streams via yt-dlp, plus BitTorrent (magnet & `.torrent`)
- Bandwidth limits, scheduling, queue priorities, SHA-256 verification and browser extensions
- `Rust` `Tauri` `TypeScript` `React`

### 🗂 [Tucklane](https://github.com/ShahzaibAnwar/tucklane)
**A quieter place for your downloads.** A privacy-first Windows organizer for your Downloads folder.
- Sorts existing and new downloads automatically, with full undo; never overwrites, never deletes
- Custom rules, duplicate finder (size → fingerprint → SHA-256), activity log, tray mode
- Works only in the one folder you approve; nothing is uploaded
- `Tauri` `TypeScript` `React`

### 🐾 PawTempo: Dog Training & Puppy Coach
A cross-platform mobile app that coaches new dog owners through training plans and puppy routines.
- `Flutter` `Dart` · Android & iOS

### 📊 [Meta Ads Live Performance System](https://www.etsy.com/listing/4436469418/meta-ads-live-performance-system-n8n)
Meta Ads API → n8n → database → live dashboard. Ready-to-use template, available on Etsy.
